# Algorithms practicing

Based on "Grokking Algorithms" book by Aditya Y. Bhargava. \
Check folders to find examples with functionality (from the table below).

<br />

| Type | Speed (Big O) | Comment |
|-|-|-|
| **Binary search** | `O(log n)` time, `O(1)` memory | |
| **Recursive binary search** | `O(log n)` time, `O(log n)` memory | Worse than iterative approach |
| **Selection sort** | `O(n^2)` time | |
| **Quicksort** | worst case `O(n^2)`, average case `O(n log n)` | Depends on chosen "pivot". But in average, average case will happen |
| **Hash tables (Map)** | worst case `O(n)`, average case `O(1)` | Depends on collisions, and on expanding hash table (takes time of `O(n)`) |
